安装 Node.js：nodejs.org/en/download，建议选 LTS 版本，全部默认选项安装。

生成 GitHub SSH 密钥

将命令中的邮箱替换为你的 GitHub 注册邮箱，执行后连续三次回车（默认生成到 ~/.ssh/id_rsa）。

提示：新版 OpenSSH 推荐用 ed25519 算法（ssh-keygen -t ed25519 -C "邮箱"，对应公钥为 id_ed25519.pub）；老系统不支持时再用上面的 rsa。

查看并复制公钥内容，粘贴到 GitHub → Settings → SSH and GPG keys：
