centos7.6用cobbler批量部署win10

发表于 2026-08-04

本文记录基于 CentOS 7.6 使用 Cobbler 通过 PXE + WinPE 方式，批量自动化部署 Windows 10 Pro（business edition, version 1809）的完整流程，包含 ADK/WinPE 定制、Cobbler 导入、无人值守应答文件、Samba 共享配置及自动化安装步骤。同时覆盖 Windows Server 2019 的复用说明与 KMS 激活思路。

==概述==

一般安装 Windows 多用 MDT 或 WDS（微软自家方案，MDT 还支持分布式镜像传输，毕竟 Windows 镜像动辄超过 4G）。本文不涉及 MDT/WDS，而是用 Cobbler + PXE + WinPE 实现无人值守批量部署。

==准备资源==

需要下载的资源：
Windows ADK（分别下载 Download the Windows ADK for Windows 10, version 1809 与 Download the Windows PE add-on for the ADK）
Windows 10 (business edition), version 1809 (Updated Feb 2019) (x64) - DVD (Chinese-Simplified)

注意事项：
ADK 的两个组件都要下载，二者均为引导包，真正的安装程序会由它们实际下载。其中 WinPE 需要约 5G 磁盘空间，占用较大。
msdn i tell you 是装机神站，但无直达页，下载时需仔细核对版本与语言，防止下错。

==安装ADK和WinPE==

已在 Windows 机器上安装 ADK 与 WinPE 插件（仅需勾选必要组件）。
安装完成后，以管理员身份打开“部署和映像工具环境”（Deployment and Imaging Tools Environment），后续命令均在该环境中执行。

==定制Win10 PE==

步骤说明：
1 本地生成 winpe 文件目录
2 dism 挂载 winpe 启动文件到 mount 目录
3 将启动命令硬编码写入 winpe 的 startnet.cmd
4 无人值守安装（PXE 启动后自动挂载 SMB 并执行 setup.exe）
5 卸载 winpe 挂载（必须执行，否则直接删文件夹会出现稀奇古怪的问题）
6 制作 win10 PE 镜像，命名为 winpe_win10_amd64.iso

关于硬编码的说明：
第三步的硬编码是无奈之举：要挂载共享文件夹必须知道 SMB 主机，而该参数难以传入 WinPE。若是 U 盘启动可写死 U 盘路径；若用 PXE 动态设置 SMB 主机，要么写死域名再做域名劫持/配置，由 startnet.cmd 下载执行 bat；要么寻找启动时传参的办法（作者未找到）；当然也可用 MDT 方案，比 PXE + 无人应答文件简单很多。

==自动化安装Windows10==

从 VMware 创建一台内存 4G、CPU 2 核、磁盘 60G 的空盘 Win10 虚拟机，然后开机。
注意事项：记得选 BIOS，别选 UEFI。
激活说明：参考 vlmcsd 搭建 KMS 服务器，可成功激活 Windows 10/Server 2019（含数据中心版）。
