prometheus和grafana搭建

发表于 2026-07-07 更新于 2026-08-05

本文记录基于 CentOS 7 使用 Prometheus + node_exporter + Grafana 搭建主机监控的完整流程，包含服务端/监控端部署、systemd 守护进程、抓取目标配置、防火墙与 SELinux 准备、Grafana 数据源与仪表盘接入，以及配置语法检查与常见排错。

==监控原理概述==

Prometheus 监控体系分为两部分：
服务端 Prometheus（prometheus-2.49.1.linux-amd64.tar.gz）：负责定时抓取（scrape）各目标暴露的指标，并存储、提供查询与告警。
监控端 node_exporter（node_exporter-1.7.0.linux-amd64.tar.gz）：部署在被监控主机上，对外暴露 /metrics 指标接口。

原理：node_exporter 在主机上启动后监听 9100 端口，持续采集 CPU、内存、磁盘、网络等系统指标；Prometheus 按配置的周期主动去这些目标的 /metrics 拉取数据，从而实现监控。Grafana 再接入 Prometheus 作为数据源，把指标画成图表。

==版本与端口说明==

组件版本：
Prometheus：2.49.1
node_exporter：1.7.0
Grafana：oss 最新

涉及端口（部署前需在防火墙放行）：
9090：Prometheus 服务端 Web/API
9100：node_exporter 指标接口
3000：Grafana Web

注意事项：
Grafana 通过 HTTP 调用 Prometheus 的 API（默认 9090）拉数据，因此若开启了 SELinux，需关闭或放通相关策略，否则 Grafana 连不上 Prometheus 的 API。

登录并接入 Prometheus 数据源：
1 浏览器打开 http://:3000，默认账号 admin / admin，首次登录会要求改密码
2 左侧菜单 ☰ → Connections → Data sources → Add data source → 选择 Prometheus
3 URL 填 http://localhost:9090（若 Prometheus 在别的机器则填其 IP:9090），其他默认
4 点击 Save & test，提示 Data source is working 即接入成功

导入 Node Exporter 仪表盘：
1 左侧菜单 ☰ → Dashboards → New → Import
2 Import via grafana.com 处输入仪表盘 ID：1860（经典 Node Exporter Full；也可使用 8919 等新版模板）
3 选择刚添加的 Prometheus 数据源，点击 Import
4 进入仪表盘后即可看到 CPU、内存、磁盘、网络等图表

==配置语法检查与排错==

写 prometheus.yml 容易因缩进/格式报语法错误，两点经验：
用 vim 的快捷键减少手敲出错：
yy：复制当前行（前面加数字可向下复制多行，如 3yy）
p：粘贴
dd：删除当前行
每次改完都用 promtool 校验：

常见排错清单：
页面打不开 / 目标不 UP：检查对应端口防火墙是否放行（9090/9100/3000）
Grafana 连不上 Prometheus：检查 SELinux 是否已关闭，以及数据源 URL 是否正确可达
配置改了不生效：确认用 systemctl reload prometheus 热加载，而非只改文件
服务起不来：journalctl -u prometheus / journalctl -u node_exporter 看详细日志
