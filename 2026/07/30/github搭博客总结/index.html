Quick Start

======================前置环境安装说明======================

安装Git：官网 git-scm.com，按需勾选桌面快捷方式，其余默认安装

安装NodeJS：nodejs.org/en/download，全部默认选项安装

1、全局安装Hexo与部署依赖

npm install hexo -g
npm install –save hexo-deployer-git

2、生成Github SSH密钥，替换为个人邮箱，执行后连续三次回车

ssh-keygen -t rsa -C “你的github注册邮箱”

查看密钥目录

cd ~/.ssh

复制id_rsa.pub内容粘贴至Github后台SSH配置页面

测试SSH连通性

ssh -T git@github.com

3、配置全局Git账号信息

git config –global user.name “liyunchen”
git config –global user.email “xxx@163.com“

======================Hexo基础指令======================

hexo new “postName” #新建文章

hexo new page “pageName” #新建独立页面

hexo generate #编译静态文件至public

hexo server #本地预览 默认4000端口 Ctrl+C关闭

hexo deploy #部署远端仓库

hexo help #查看帮助文档

hexo version #查看Hexo版本

初始化博客（当前文件夹必须为空）

hexo init
hexo g

======================部署Next主题======================

git clone https://github.com/next-theme/hexo-theme-next themes/next

修改配置文件theme字段为next

sed -i ‘s/theme: landscape/theme: next/‘ _config.yml

清理缓存启动预览

hexo clean && hexo s

预览地址：localhost:4000

写入站点基础配置

cat >> _config.yml <<EOF

Site

title: 个人学习记录
subtitle: ‘’
description: ‘’
keywords:
author: kezi
language: zh-CN
timezone: Asia/Shanghai
EOF

修改配置生效命令

hexo clean

hexo g

hexo d

======================配置Github Pages部署======================

提前网页创建仓库：liyunchen.github.io

cat >> _config.yml <<EOF
deploy:
type: git
repo: git@github.com:liyunchen/liyunchen.github.io.git
branch: main
EOF

执行推送部署

hexo d

=====================日常固定操作命令(Next官方模板)=====================

Create a new post

$ hexo new “My New Post”

生成路径：source/_posts/*.md

文档参考：https://hexo.io/docs/writing.html

Run server

$ hexo server

文档参考：https://hexo.io/docs/server.html

Generate static files

$ hexo generate

文档参考：https://hexo.io/docs/generating.html

Deploy to remote sites

$ hexo deploy

文档参考：https://hexo.io/docs/one-command-deployment.html

=====================简写命令汇总=====================

hexo generate = hexo g

hexo server = hexo s

hexo deploy = hexo d

hexo new page “pageName” 新建独立页面
