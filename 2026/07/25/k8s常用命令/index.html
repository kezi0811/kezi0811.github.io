k8s常用命令

发表于 2026-07-25

本文整理 Kubernetes 日常运维中最常用的 kubectl 命令，覆盖资源查看、进入容器、日志与详情排查、资源删除等高频场景，并附一份高频补充命令清单，方便随用随查。

获取资源（Pod / 各类对象）

常用选项：

  • -A / --all-namespaces：查看所有命名空间的资源
  • -n <namespace>：指定命名空间，默认 default；集群核心组件多运行在 kube-system
  • --show-labels：显示资源携带的标签
  • -l key=value：按标签筛选资源（也可只写 key）
  • -o wide：输出详细信息，包括 Pod IP、所在节点等
  • -w：实时监视资源对象的变化（类似 watch）

进入容器执行命令

  • -it：分配交互式终端（进入容器排错必备）
  • -c <cName>：指定容器；Pod 内只有一个容器时可省略，默认进入该容器

查看字段说明（API 文档）

查看某资源字段的官方说明，可逐级下钻，例如 kubectl explain pod.spec.containers。写 YAML 不确定字段时很实用。

查看容器日志

  • -c <cName>：多容器 Pod 中指定容器
  • 加 -f 可实时跟踪日志（类似 tail -f）

查看资源详情

输出事件（Events）、状态、关联资源等详细信息，是定位 Pod 起不来、镜像拉取失败等问题的首选命令。

删除资源

  • --all：删除当前命名空间下该类型的所有资源对象
  • 跨命名空间批量删除需额外加 -A

补充高频命令

提示：以上命令默认作用于 default 命名空间，操作其他命名空间时记得加 -n <namespace>。
