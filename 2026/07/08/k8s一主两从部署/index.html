k8s一主两从部署

发表于 2026-07-08

本文记录基于 Rocky Linux 9.8 使用 kubeadm 部署 Kubernetes 1.29 一主两从集群的完整流程，涵盖环境规划、系统初始化（网卡/软件源/防火墙/Selinux/swap/hosts）、Docker 与 cri-docker 安装、kubeadm 初始化与节点加入，以及 Calico 网络插件部署，实现集群网络扁平化。

==环境规划==

宿主机 VMnet1 配置为 192.168.66.52。
统一 Rocky Linux 9.8 最小化安装；用 iKuai 32 位模拟生产环境路由器。

节点规划：
iKuai：192.168.66.200，mem=1GB，disk=8GB
master：192.168.66.11（RL-1），cpu=4（2,2），mem=4GB，nic>=1，disk=100GB
node1：192.168.66.12（RL-2）
node2：192.168.66.13（RL-3）
自定义分区：/boot 800MB、/swap 4GB、其余给 /。
网卡：第一块仅主机模式，第二块 NAT（后续删掉 NAT）。
iKuai 默认账号密码 admin / admin。

课外：为什么不能只靠 docker 来跑 k8s —— docker run –restart=always 只是 docker 启动时给容器传达一个启动信息，容器没启动成功也不会继续传达，无法保障组件正常工作，所以需要 kubelet，要给 kubelet.service 自启权限。
启动顺序：linux → docker → cri-docker → kubelet → 其他组件。
